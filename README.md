# My Portfolio Website

A personal portfolio website built with HTML and CSS showcasing my background, skills, and professional experience.

## 📁 Project Structure

```
Website-Portfolio/
├── home.html           # Landing / main page
├── about.html          # About me page
├── professional.html   # Professional experience page
├── style.css           # Global stylesheet
├── profile.png         # Profile photo
├── background.jpg      # Background image
├── celcomdigiposter.jpg  # Project poster (Celcom Digi)
├── event-photo1.png    # Event photo 1
├── event-photo2.jpg    # Event photo 2
└── robots.txt          # SEO crawl rules
```

## 🌐 Pages

- **Home** — Introduction and navigation
- **About** — Personal background and interests
- **Professional** — Work experience and achievements

## 🛠️ Built With

- HTML5
- CSS3

## 🚀 Getting Started

Clone the repository and open `home.html` in your browser:

```bash
git clone https://github.com/zlaikhaa/Website-Portfolio.git
cd Website-Portfolio
open home.html
```
